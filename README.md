# Amazon-Sales-Performance-Dashboard-Analysis-Excel-

## Project Overview

This project analyzes Amazon sales data using Microsoft Excel.

The dashboard provides insights into:

- Total Sales Performance
- Product-wise Sales Analysis
- City-wise Sales Analysis
- State-wise Sales Analysis
- Regional Performance
- Monthly Sales Trends

## Dataset Information

Records: 10,000

Columns:

- Date
- Sales Rep
- Product
- Units
- Price
- Total Sales
- City
- State
- Region
- Day

## Business Objectives

1. Identify top-performing products.
2. Analyze regional sales distribution.
3. Track monthly sales trends.
4. Evaluate city and state performance.
5. Support data-driven business decisions.

## KPIs

### Sales KPIs

- Total Revenue
- Total Units Sold
- Average Sales per Transaction

### Location KPIs

- Top City by Revenue
- Top State by Revenue
- Best Performing Region

### Product KPIs

- Top Selling Product
- Lowest Selling Product

## Dashboard Features

### Product Analysis

- Product-wise Revenue
- Product-wise Units Sold

### Geographic Analysis

- City-wise Sales
- State-wise Sales
- Regional Performance

### Trend Analysis

- Monthly Revenue Trend
- Daily Sales Trend

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Dashboard Design

## Key Insights

- Delhi generated the highest sales revenue.
- Maharashtra is the top-performing state.
- Smarties Pop-Up is the highest-selling product.
- West region contributes significantly to total revenue.
